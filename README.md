# VISIT 홈페이지 리뉴얼 시안 — 3D 공간

360 이미지 기반 VR 공간 웹을 만드는 비지트(VISIT)의 홈페이지 리뉴얼 디자인 시안입니다.
홈페이지 자체가 하나의 3D 공간이 되도록 구성했습니다.

> 디자인 시안이며 실제 서비스 화면이 아닙니다. 버튼과 메뉴 링크는 연결되어 있지 않습니다.

## 시안 목록

| 파일 | 내용 |
| --- | --- |
| `index.html` | 시안 목록 |
| `a-space-tour.html` | **A — 360 공간 투어.** 폴리곤 구 안에서 핫스팟으로 7개 섹션을 이동하는 메인 전체 |
| `a-space-tour-mobile.html` | **A 모바일.** 390×844 기준 화면과 전체 화면 메뉴 |
| `b-walkthrough.html` | **B — 워크스루.** 실내·실외 프레임을 통과하며 앞으로 걸어가는 히어로 대안 |
| `c-panorama-unfold.html` | **C — 파노라마 언폴드.** 2:1 파노라마가 구로 말려 올라가는 히어로 대안 |

## 보는 방법

빌드 과정이 없는 정적 페이지입니다. 폴더에서 간단한 서버를 띄우면 됩니다.

```bash
python3 -m http.server 4173
```

그다음 `http://localhost:4173` 을 엽니다. GitHub Pages를 켜면 주소만으로도 볼 수 있습니다.

A안 조작: 드래그로 둘러보기, 핫스팟 클릭·스크롤·Prev/Next로 섹션 이동.
주소 뒤에 `?accent=FF5A1F` 처럼 붙이면 강조색을 바꿔 볼 수 있습니다.

## 디자인 기준

현재 visitinc.kr에서 가져온 값입니다.

- 색: 프라이머리 `#FF004D`, 딥 다크 `#00060C`, 잉크 `#212324`, 보조 회색 `#979797`
- 서체: 한글 Pretendard(없으면 Noto Sans KR), 영문 메뉴·라벨 Poppins 500
- 버튼: 8px 라운드 레드 버튼, 히어로의 흰색 알약형 버튼

## 알아둘 점

- 3D는 외부 라이브러리 없이 2D 캔버스에 직접 그렸습니다. 실제 개발은 three.js 기반을 전제로 합니다.
- 구 안쪽은 실제 360 이미지가 아닌 추상 폴리곤입니다. 실제 구현에서는 촬영한 파노라마를 입힙니다.
- Growth 섹션의 연도 계단 높이는 실제 수치가 아닌 상징적 표현입니다.
- `dc-lite.js`는 디자인 캔버스에서 내보낸 화면을 단독 페이지로 실행하기 위한 작은 런타임입니다.
